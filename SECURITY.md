# Security

Please report vulnerabilities privately through [GitHub security advisories](https://github.com/Hydrada/OpenDraft/security/advisories/new), not in public issues. Include the version, steps to reproduce and, if relevant, a minimal PDF that triggers the problem.

OpenDraft opens untrusted PDFs, so reports about crafted documents (script execution, file access, network requests, crashes) are especially welcome. Only the latest release receives fixes.
